# 🥤 Sabor-Refri

> Uma landing page interativa e responsiva com um carrossel animado para exibição de sabores de refrigerantes.

---

## 💻 Sobre o Projeto

O **Sabor-Refri** é um projeto de front-end focado na experiência visual do usuário. Ele apresenta um carrossel dinâmico onde cada slide altera completamente a identidade visual da página (incluindo cores de fundo temáticas, títulos estilizados e imagens sobrepostas com efeito de profundidade), proporcionando uma transição fluida entre os sabores de Morango, Laranja e Abacate.

---

## 🚀 Funcionalidades

* **Carrossel Interativo:** Navegação entre os sabores utilizando botões direcionais (`<` e `>`).
* **Mudança Dinâmica de Tema:** O fundo altera sua cor via variáveis CSS (`--background`) de acordo com o sabor selecionado.
* **Animações Fluidas:** Efeitos de transição (`@keyframes`) nos elementos visuais ao alternar os slides.
* **Efeito de Profundidade:** Utilização de camadas (`z-index`) separando imagens de primeiro plano (frutas com desfoque) e plano de fundo (lata/garrafa).
* **Totalmente Responsivo:** Interface adaptada com `media queries` para o funcionamento ideal em Tablets e Dispositivos Móveis.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web nativas:

* **HTML5:** Estruturação semântica da página e dos blocos do carrossel.
* **CSS3:** Estilização avançada, posicionamento absoluto, variáveis de ambiente CSS, animações customizadas e design responsivo.
* **JavaScript (Vanilla):** Manipulação dinâmica das classes do DOM para controle do fluxo dos slides (`prev` e `next`).

## 📦 Como Executar o Projeto

Como o projeto utiliza apenas arquivos estáticos nativos (HTML, CSS e JS), não é necessário instalar dependências de gerenciadores de pacotes.

### ⌨️ Passo a Passo

1. **Clone este repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd Sabor-Refri
   ```

3. **Abra o projeto:**
   * Basta dar um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador, ou
   * Utilize a extensão **Live Server** no seu VS Code para rodar um servidor local de desenvolvimento.
